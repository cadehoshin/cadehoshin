## 🚀 Featured Project

### PDF Analyzer by LAUVRE

An AI-powered PDF question-answering application that allows users to ask questions about their documents and receive answers grounded in retrieved document content.

**Key features**
- PDF text extraction using PyMuPDF
- Text chunking with overlap
- Semantic search using text embeddings
- Context-aware answer generation
- Source references with page numbers
- Local LLM inference using Ollama

**Tech stack:** Python · Streamlit · Ollama · Llama 3.2 · Nomic Embed Text · PyMuPDF
